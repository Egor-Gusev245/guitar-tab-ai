# Guitar AI Studio 🎸

Интерактивное веб-приложение для гитаристов:
* **Синхронный показ аккордов (Гармония)** в реальном времени во время воспроизведения.
* **Разделение на стемы (Facebook Demucs `htdemucs_6s`)**: караоке-режим / минусовка (Play-Along) с отключением гитары и подыгрыванием под трек.
* **Снятие гитарных табулатур (Spotify Basic Pitch)** на любом выбранном кусочке песни (Standard Tuning EADGBE).

---

## 🎨 Дизайн и стилистика

Интерфейс выполнен в премиальной темной гамме: **глубокий черный уголь (Obsidian Black) + неоновый королевский фиолетовый (Neon Violet) + чистый белый (Crisp White)**.

---

## 🎛️ Новые возможности

1. **Режим Play-Along (Минусовка для гитариста)**:
   * Сначала мгновенно рассчитывается и выводится гармония (аккорды).
   * По кнопке **«Разделить на стемы (Demucs)»** создаются изолированные дорожки:
     * 🎸 **Гитара (Guitar Stem)**
     * 🥁 **Минусовка (Без гитары: Бас + Барабаны + Вокал + Клавиши)**
   * Можно заглушить оригинальную гитару (кнопка *«Выключить»* или ползунок в 0%) и **играть самому под оригинальный минус песни, глядя на сменяющиеся сверху аккорды**!
2. **Ограничение на снятие табов при выключенной гитаре**:
   * Если в микшере гитара заглушена или её громкость выставлена на 0%, кнопка *«Снять табы»* блокируется с предупреждением:
     *«⚠️ Гитара выключена (громкость 0%). Включите гитару в микшере выше, чтобы снять табы!»*.
3. **Исправление аудиоплеера**:
   * Добавлена полная поддержка декодирования URL (`urllib.parse.unquote`) для треков с пробелами, скобками и кириллицей (например, *`Nirvana - About A Girl (hitmos.fm).mp3`*).

## 🚀 Запуск через CMD

1. Откройте `cmd` и перейдите в папку проекта:
   ```cmd
   cd /d "C:\Users\egorg\.gemini\antigravity\scratch\guitar_tabs_mvp"
   ```
2. Запустите студию:
   ```cmd
   python start_studio.py
   ```
   *(или дважды кликните по `start_studio.bat`)*.

3. Браузер откроется на: **`http://127.0.0.1:8080`**.
